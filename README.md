# Styling Paradigms Assignment

This repository contains two independent React and TypeScript exercises:

- `exercises/tailwind-dashboard`: responsive product dashboard using Tailwind CSS
- `exercises/vanilla-extract-library`: type-safe component library using Vanilla Extract

Each exercise has its own dependencies, lockfile, and development commands.

## Tailwind dashboard

```bash
cd exercises/tailwind-dashboard
npm install
npm run dev
```

## Vanilla Extract component library

```bash
cd exercises/vanilla-extract-library
npm install
npm run dev
```
